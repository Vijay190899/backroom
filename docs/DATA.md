# Data Sources & Honesty Notes

Backroom uses **open or synthetic data only**. Nothing is collected from real people or businesses. Every synthetic element is labelled here and in the UI ("Synthetic" chip on the evidence drawer).

| Dataset | Source | Licence / terms | Use | Transform |
|---|---|---|---|---|
| Coffee shop transactions | Maven Analytics Data Playground, "Coffee Shop Sales" (~149k rows, 3 NYC stores, Jan–Jun 2023) | Free dataset, **verify redistribution terms before committing any raw rows** | POS sales for Hafer & Bohne | Keep 1 store; USD→EUR with café-style rounding; shift dates by a multiple of 7 days so the window ends "today" (weekdays preserved); rename products to a Bonn café menu via a mapping file |
| Weather (history + forecast) | Open-Meteo (`archive-api.open-meteo.com`, `api.open-meteo.com`), Bonn 50.73 N 7.10 E | Free, CC BY 4.0, attribution required | Weather-demand detector, rainy-Saturday card | Daily precip/temperature |
| Public holidays | Nager.Date (`date.nager.at`, DE / NRW) | Free | Demand adjustments | — |
| Recipes / BOM | Hand-authored `data/recipes.yaml` | Ours | Margin calculation | — |
| Supplier prices & invoices | Generated by the Grainline mock portal | Ours | Memory ingest, margin erosion | Scripted events: butter +18% (day −9), oat milk +9% (day −3) |
| Staff, rota, owner preferences | Generated (`data/seed/*.yaml`) | Ours | Labour, verifier rules | Fictional names |
| Inventory | Simulated: opening stock + deliveries − (sales × BOM) | Ours | Stock-out detector | — |

## Honesty notes (say these out loud if asked)
- Sales are **NYC data re-based to Bonn**. Absolute levels are not a real Bonn café's.
- Bonn weather is real, but the sales never "saw" it. The weather-demand effect is **synthesised**: a documented, seeded multiplier (e.g. −14% footfall on rainy Saturdays) applied to the re-based sales. With real merchant data the detector would estimate it (method: simple regression on precipitation buckets × weekday).
- All benchmark questions (B3) have ground truth computed by SQL on this same data.

## Pipeline
`uv run python -m data.pipeline all` → `data/out/*.parquet` + `data/out/seed.sql`. It is idempotent and seeded (`DATA_SEED=44`). Raw downloads go to `data/raw/` (gitignored).
